Disassembler

ARM64 · x86-64 · ARM32 · WebAssembly · .NET · JVM · one file · offline

Take a program
apart

Open a program for a Mac, an iPhone, Android, Windows or Linux — an app's executable, a .dylib, a whole iOS app (.ipa), an Android library, a .so (or the whole .apk), an .exe or .dll, native or .NET —, Java bytecode (a .class or a .jar), or a WebAssembly module, a .wasm file. Every instruction is decoded and explained, counted, and shown as assembly or as HLA64. Nothing is uploaded: the file is read by this page.

Open a program or drop it here

An app's program is inside the bundle: Name.app/Contents/MacOS/Name. In the Finder, Show Package Contents opens it; an iOS app (.ipa) or a zipped app opens whole, and you pick its program or one of its frameworks. An Android app's libraries are inside its APK: open the APK and pick one. A web page's module can be saved from the Network tab of its developer tools.
